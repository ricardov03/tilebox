# tilebox v0.1.0

## Summary
tilebox is a personal link page: one profile block and a grid of tiles that you arrange yourself, like Bento.me. You edit the page in a local editor in your browser, pick a color preset and a font preset, and save. The result is a set of static files that you host on Cloudflare Pages or Netlify, with no server and no database.

## Changes
- Public page with a profile block: avatar, name, handle, bio and a status line.
- Seven tile types: link, social, image, text, section title, map and video.
- Four tile sizes (1x1, 2x1, 1x2, 2x2) on a 4-column grid, 2 columns on phones.
- Separate tile order for desktop and phone.
- Three color presets (condomera, lunchbox, night) and three font presets (geist, lunchbox, night).
- Light, dark and system mode with a toggle that remembers your choice and does not flash on load.
- Link tiles show an icon you pick or the site's favicon, fetched once at build time.
- Video tiles show a thumbnail and load the player only when you click.
- Local editor at `/edit`: add, edit, delete, resize and drag tiles; pick icons from Iconify; upload images; save with Cmd/Ctrl+S.
- The editor and its save route never ship to production.
- Static output with no runtime network calls and no third-party scripts on the public page.
- Build-time checks for the profile file, color contrast, icon names and favicons.
